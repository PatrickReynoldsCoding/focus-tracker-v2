# Browser checks

Playwright scripts that click through the app against a local server (`npm run build && npx wrangler dev --port 8787 --persist-to /tmp/ft-ui`). `seed.mjs` fills it with sample data; `part1` (Notes tab), `part2` (themes, all four at phone and desktop width), `part3` (Back and swipe), `plan` (Plan my week, light and E-ink at 390 and 1280 px), `appearance`, `overflow`, `offline` (offline use: opening with no signal, the queue, a reload while offline, conflicts, a new deploy; needs a freshly seeded server; it edits `public/` for the deploy step and puts it back), `layout` (the desktop grid in Today's All pill and on a project page, straight on the page: drag by the title, the corner to resize, handles hidden until hovered, text still selectable, the ⋯ menu's Auto height, Pop out, Remove, Add panels and Reset; Today's pills on a computer: the usual pills, each pill's own grid, + New pill, ✎ Edit pill, ⋯ Remove from this pill, the All switch; on a phone: Today settings and swipes; arranging on a phone: a long press (not in a field, not while scrolling, not ticking the to-do under the finger), drag up with the page scrolling, the height handle and Auto height, Back, a tap outside, Remove and Add panels in the All pill, Done, the project page and the keyboard; pop-out windows; a move made offline; flags off one by one and together; light and E-ink at 1280 and 390 px; needs a seeded server; `layout.mjs grid|desk-pills|pills|arrange|popout|offline` runs one part), `today-list` (the Today list: what it gathers and its order, tick, Not today, Show and Undo, add, opening a card and a to-do's list, a card's day in its dialog and on its tile, all done, a change made elsewhere showing when the app comes back, a tick made offline, an old saved pill naming `todos`, the flag off; light, dark and E-ink at 390 and 1280 px; needs a seeded server and puts the data back as it was). `files` (the Files tab: Notes and Whiteboards tabs replaced, old #/notes and #/whiteboards addresses, top level and project folders, type chips, search by name, note text and folder, sort, grid and list, New folder, note and link in the folder on screen, Rename, Move… with the folder picker on a phone, drag onto a folder and onto the path, deleting a folder that is not empty with Undo, a project's notes on their own page, the flag off; light, dark and E-ink at 390 and 1280 px; needs a seeded server and puts the data back). `add-panel` (+ Add panel: in the pill bar and under the panels, the sheet with icons and Add file, the file picker's recent files, type chips, search, project folder and path, + New, a file put on Today and in the pill and scrolled into view, Remove taking it off Today and out of every pill, the All pill, the ⋯ menu's Add panel…, a project page (a removed panel back, a file into the project's folder), the phone and E-ink, the flag off; needs a seeded server and puts the data back). `part1` and `appearance` turn the `files-tab` flag off while they check the Notes tab's cards, and back on. Run `plan` before `ui-smoke.mjs` on a server: the smoke check adds a second "Run" habit and leaves data that `plan` does not expect. Screenshots go to `$FT_SHOTS` (default /tmp/ft-ui-shots). `../ui-smoke.mjs` is the quick check run before every release.
