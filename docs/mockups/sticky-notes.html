Rules I would use

✓ New panel type "Sticky notes" in the Add panel; also quick-add button on Today.
✓ Tap a sticky to edit text, colour (6 colours), and optional "show until" date; expired ones fold into "Old stickies".
✓ A sticky can be turned into a to-do or a full note (one tap).
✓ Per profile, no project link. Claude can add and read stickies. E-ink shows them as white boxes with a black edge.
