How it works: pin up to 3 cards in order (⋯ → Focus on this / Add to up next). Ticking "Now" moves the next one up. Each time the timer ends, you're asked whether the card is done, so drifting gets noticed. Most help staying on track; also the most to build.

My pick: A first (small), with C's check-in at the end of the timer added later.
