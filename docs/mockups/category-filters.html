Projects: big category buttons (mockup)

A switch in Settings → Features (category-buttons, off by default). When on, big coloured buttons sit above the project list and filter it. Tap a button to show only that category; tap it again (or "All") to clear. Three options below, each on a computer and a phone. Pick one, or mix them.

A. Tiles with counts

Large squares, one per category, each with the number of projects. Most colourful and easiest to hit. Takes the most room (two rows on a computer, 3 rows on a phone).

Shared behaviour (all three)

Colours: each category gets a strong colour (you can change it in Manage categories). In E-ink the colour becomes a black outline and a selected button turns solid black, so it never relies on colour. The buttons are clickable here to try the selection. Options for you to pick later: tap more than one category at once; hide categories with no projects; remember the choice per device.
