## What to release (Android)

The signed APK was not made. Two things were missing:

1. **Signing key.** The release build reads `~/.android-keys/mpe-instruments.properties` (or the path in `FT_SIGNING`). It was not on this Mac. **Do not make a new key.** The phone's app was signed with the old key, so an APK signed with a new key cannot install over it.
2. **GitHub release.** `gh` is logged in to the work account only. CLAUDE.md forbids `gh` for personal repos. Patrick publishes the release in the GitHub web page.

Steps:

```
cd ~/personal-repos/focus-tracker-v2/android
ANDROID_HOME=/opt/homebrew/share/android-commandlinetools \
JAVA_HOME=/Users/paddymac/Library/Java/JavaVirtualMachines/corretto-17.0.12/Contents/Home \
./gradlew assembleRelease
cp app/build/outputs/apk/release/app-release.apk focus-tracker-0.3.4.apk
```

Then, on GitHub (personal account), make a **published** (not draft) release for `PatrickReynoldsCoding/focus-tracker-v2`:

- Attach `focus-tracker-0.3.4.apk`.
- Put this on its own line in the notes: `versionCode: 7`

The in-app updater only sees a published release with that asset name and notes line.
