3 · Profiles with their own theme

Two ways to set it. Both use the existing 'This profile / All profiles' choice, so one theme for everything is still the default.

A · In Manage profiles
PersonalForest ▾
WorkMidnight ▾

Theme sits beside the profile name. Switching profile changes the whole look at once, so you always know where you are.
B · Profile colour tints the theme
Personaluses profile colour
Workuses profile colour
Side projectuses profile colour
No new choice. One chosen theme everywhere, but each profile's colour becomes the accent. Less control, less setup.

My recommendation

Start with these 8 themes. Use A (each profile picks its own theme, default 'same as app'). Also keep E-ink as a separate switch for the reader.
